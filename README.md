# 💱 PKR ↔ USDT Currency Converter (Python CLI)

A simple command-line currency converter built in Python that converts:

- PKR to USDT
- USDT to PKR

## 🚀 Features

- Simple CLI interface
- Continuous loop until user quits
- Error handling for invalid input
- Clean and readable code

## 💰 Exchange Rate

1 USDT = 280 PKR  
(Note: You can change the rate in the code.)
